# chat-app

Features
Real-Time Messaging: Users can send and receive messages instantly.
Video Call: Initiate a video call within the chat room using WebRTC.
Typing Indicator: Displays when someone is typing a message.
Message History: Messages are saved in the browser's local storage, persisting the chat history across sessions.

Technologies Used
React
Socket.IO
WebRTC
Node.js
Express.js

Getting Started-
Installation
Clone the repository:
https://github.com/shahnawaz0011/chat-app.git
Navigate into the project directory:
cd chat-app
Install the dependencies:
npm install
start server:
npm start


Open the application in your browser:

Frontend: http://localhost:3000

Backend: http://localhost:3001

Usage
On the main page, enter a username.
Click Start a New Chat to join the chat room.
Send messages, initiate a video call, and interact with other users.
